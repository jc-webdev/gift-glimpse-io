# Wishlist Connect

Zbuduj mobile-first prototype aplikacji społecznościowej do prywatnych wishlist i prezentów.

To ma być nowoczesna aplikacja typu social wishlist: użytkownik zapisuje pomysły na rzeczy, doświadczenia i wydarzenia, a następnie decyduje, które grupy mogą je zobaczyć. Główny sens: znajomi i rodzina widzą to, czego użytkownik naprawdę chce, bez proszenia go o listę prezentów. Ważna jest prywatność i element niespodzianki.
